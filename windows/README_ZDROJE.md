# Zdrojové soubory Windows verze

- `app.py`, `engine.py`: Python aplikace 0.8.1 upravená pro Windows i Linux.
- `assets/`: ikony ovládacích prvků pro všechny vzhledy.
- `requirements-build.txt`: reprodukovatelné balíčky pro sestavení instalátoru.
- `instalator.iss`: český instalátor Inno Setup, instalace pro aktuálního uživatele bez nutnosti oprávnění správce.
- `SESTAVIT_WINDOWS.ps1`: místní automatické sestavení EXE a Setup.exe.
- `test_*.py`: kontrola výpočtů, souborů, barev a cest na Windows.

Ostatní verze v kořeni repozitáře a v `historie/` se nemění. Vydání pro Windows odpovídá verzi 0.8.1, opravuje mimo jiné názvy zakázek s českou diakritikou. Neobsahuje osobní data o filamentech.
