- Při ukládání zakázky se v automatickém návrhu názvu zachovávají české znaky a mezery: `Dárek Aleš` → `Dárek Aleš.3dk.json`.
- Neplatné znaky v názvech se bezpečně nahrazují.
- Starší projekty zůstávají kompatibilní, výpočty a PDF export se nemění.
- Doplněny regresní testy pro práci s Unicode. Automatických testů prošlo 24.

**Soubory vydání:** kompletní instalační ZIP pro Linux a menší ZIP jen s opravou. Pro instalaci z úplného archivu použij `./spustit.sh` a postup v README. Archiv neobsahuje instalované Python závislosti – ty se instalují dle návodu.
