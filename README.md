# Kalkulačka 3D tisku

Praktická aplikace v Pythonu pro výpočet nákladů a prodejních cen výrobků z 3D tiskárny. Je určená především českým uživatelům.

## Jak kalkulačka funguje

Kalkulačka vychází z údajů v **G-code souborech vytvořených v Bambu Studiu**. Pro výpočet využívá informace o spotřebě filamentu a době tisku. Na jejich základě pomáhá spočítat náklady na materiál, elektrickou energii a opotřebení tiskárny a stanovit výslednou prodejní cenu.

## Hlavní funkce

- Kalkulace ceny spotřebovaného filamentu.
- Zohlednění doby tisku, elektřiny a provozních nákladů tiskárny.
- Nastavení zisku a výpočet prodejní ceny.
- Výpočet více tiskových položek a jejich společného souhrnu.

## Pro koho je aplikace určená

Pro hobby tiskaře a menší tvůrce, kteří chtějí mít přehled o nákladech na 3D tisk a jednoduše stanovovat cenu výrobků.

## O projektu

Nejsem profesionální programátor. Tuto aplikaci vytvářím s pomocí umělé inteligence podle vlastních potřeb a zkušeností s 3D tiskem. Projekt průběžně vylepšuji.
